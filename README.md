# Projet BDD

Interface statique réalisée en groupe autour d’un mini-projet de base de données. Cette version reprend l’interface du projet d’origine pour la rendre consultable directement dans un navigateur.

## Parcours

- Rechercher un pseudonyme depuis `index.html`.
- Consulter la liste des fiches depuis `liste.html`.
- Ouvrir une fiche et accéder à sa page de modification.

## Technologies

HTML, CSS intégré et JavaScript.

## Limites de cette version

Il s’agit d’une adaptation statique du projet initial en PHP et WAMP. Les fiches sont représentées par des pages HTML distinctes : les modifications ne sont pas enregistrées et l’ajout d’un utilisateur demande de créer ses pages.

Le projet a été réalisé en groupe à l’UMMTO.
